## 2026-08-09 — Add a Concepts Index page with DefinedTermSet markup

- **What** — A new root page, `concepts.qmd`, gives readers a navigation aid across 23 Deming concepts (the Funnel Experiment, the 14 Points, tampering, the System of Profound Knowledge, and so on). Each entry is a one-line orientation — deliberately not a full definition — plus a deep link to the chapter where the course actually teaches it, using the existing `{#sec-pageN}` anchor convention. The page is marked up as `DefinedTermSet`/`DefinedTerm` JSON-LD via a new `assets/schema/concepts-jsonld.html`, included only by `concepts.qmd`, following the same `include-in-header` mechanism as `assets/schema/course-jsonld.html` on `index.qmd`.
- **Where** — New file `concepts.qmd` at the project root, added to `book.chapters` in `_quarto-en.yml` immediately after `privacy.qmd`, and enumerated in `.pa11yci.json` immediately after `what-this-course-covers.html`. New schema file `assets/schema/concepts-jsonld.html`. `content/appendix/glossary.qmd` gained a short cross-link sentence pointing to this page, and `docs/glossary-audit.md` gained a note under "Headroom" pointing at it too, so a future reader of the audit understands why the ~10-term cap still stands alongside a much larger page.
- **Source reference** — n/a. This page never existed in Neave's PDFs; the one-line orientations are Lee's own editorial summaries, written to point rather than to teach, and the deep links reuse existing course anchors and the seven `<dfn>` anchors already present in `content/appendix/glossary.qmd` — no new `<dfn>` markup was added anywhere.
- **Why** — Part of the SEO/GEO epic [#497](https://github.com/lddurbin/twelve_days_to_deming/issues/497), decided as a follow-on once [`docs/glossary-audit.md`](https://github.com/lddurbin/twelve_days_to_deming/blob/main/docs/glossary-audit.md) confirmed the appendix glossary's ~10-term cap should hold: several high-search-volume Deming terms (the funnel experiment, the Joiner Triangle, appreciation for a system) were explicitly rejected from the glossary because a glossary entry for every term Neave introduces "invites readers to look up rather than read." That pedagogical objection doesn't apply to a page framed purely as a map: the glossary defines the handful of terms a reader must hold in mind to follow Neave's argument at the point they first meet them; this index answers "does this course cover X, and where?" for a reader arriving from a search engine who doesn't yet know the course exists. Different job, different failure mode — so it lives on a separate page rather than expanding the glossary's cap.
