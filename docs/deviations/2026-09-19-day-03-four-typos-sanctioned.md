## 2026-09-19 — Four Day 3 typos sanctioned retroactively

- **What** — At some undetermined point the site silently corrected four one-word typos in Neave's Day 3 text, and none of the corrections was logged. All four are kept, not reverted, and no `[sic]` marker is added:
  1. "measures variation **in** a completely different way". The PDF prints "measures variation **is** a completely different way".
  2. "there's a lot **of** it!". The PDF prints "there's a lot **if** it!" in bold italic (confirmed on the page image).
  3. "to put **it** mildly". The PDF prints "to put **in** mildly".
  4. "Just **in** case you really cannot find any dice". The PDF prints a stray capital: "Just **In** case".
- **Where** — `content/days/day-03/05-how-do-we-compute-control-limits.qmd` (items 1 and 2); `content/days/day-03/10-introduction-to-the-funnel-experiment.qmd` (items 3 and 4).
- **Source reference** — `F.Day.3.13Jan20.pdf`, printed pages 14, 16, 35 and 37 (PDF pages 18, 20, 39 and 41).
- **Why** — Each slip has only one plausible intended reading. Earlier versions of this log's rules called corrections like these mechanical and exempted them, but in practice the typo corrections found since Day 7 were logged anyway. [#831](https://github.com/lddurbin/twelve_days_to_deming/issues/831) makes that practice the rule: every typo correction gets an entry, so that anyone checking the site against the PDF finds each changed word accounted for. These four were first adjudicated before that decision (three were rejected for logging and one was left for discussion), so they are logged here under the settled rule.
